RULES  WSU Pseudocode Conventions

At WSU, pseudocode always starts with BEGIN, ends with END, and uses capital keywords. Variables must be DECLAREd before use.

BEGIN -- Declare ALL variables first (group them) DECLARE VARIABLE1 AS STRING DECLARE NUMBER1, NUMBER2 AS REAL DECLARE TOTAL AS REAL -- Input DISPLAY "Enter a value: " ACCEPT NUMBER1 -- Processing TOTAL = NUMBER1 + NUMBER2 -- Output DISPLAY "The total is " TOTAL END

KEYWORDS  Essential Pseudocode Keywords

STRUCTURE
BEGIN END DECLARE x AS REAL DECLARE x AS INTEGER DECLARE x AS STRING
INPUT / OUTPUT
ACCEPT variableName DISPLAY "message" DISPLAY "text" variable OUTPUT variableName
SELECTION
IF condition THEN statements ELSE statements ENDIF

⚠ Important: In pseudocode, use REAL for decimal numbers, INTEGER for whole numbers, and STRING for text. Variable names must be legal — no spaces, no special characters.

📝 Example: Average of two test marks

Ask the user to input a student's ID number and two test marks. Calculate and display the average mark.

BEGIN DECLARE IDNUMBER AS STRING DECLARE TESTMARK1, TESTMARK2 AS REAL DECLARE AVERAGE AS REAL ACCEPT IDNUMBER ACCEPT TESTMARK1 ACCEPT TESTMARK2 AVERAGE = (TESTMARK1 + TESTMARK2) / 2 DISPLAY "AVERAGE IS " AVERAGE END
// 01 — analysis tool

IPO Charts

An Input → Processing → Output chart is used during the Analysis phase to understand and break down a problem before writing any code.

What is an IPO Chart?

An IPO chart is a 3-column table that helps you analyse a problem by identifying what goes in (input), what must happen (processing), and what comes out (output).

There are many formats for IPO charts. At WSU, we follow the rules specified in the Module 4 notes exactly.

📥 INPUT Column

  • List of inputs (nouns)
  • Look for: accept / ask the user / get
  • Use legal variable names
  • No spaces, no specials

⚙️ PROCESSING Column

  • List of actions (verbs)
  • Simple English only — NOT pseudocode
  • Show WHAT to do, not HOW
  • No detailed calculations

📤 OUTPUT Column

  • List of outputs (nouns)
  • Look for: display / show / print
  • Use legal variable names
  • For messages, just write "message"

How to fill in an IPO Chart — Step by Step

Read the problem carefully

Identify every input and output. How many variables do you need?

Make up variable names for each input and output

Write them in the INPUT and OUTPUT columns.

List all actions needed in simple English

In the correct order, in the PROCESSING column. Do NOT write pseudocode here.

Example 1: Add three numbers

"Accept three numbers, add them together and display the total."

INPUT PROCESSING OUTPUT
NUMBER1
NUMBER2
NUMBER3		 Accept 3 numbers
Add the 3 numbers together
Display the total		 TOTAL

Example 2: Student average mark

"Ask the user to input a student's ID number and two test marks. Calculate and display the average mark."

INPUT PROCESSING OUTPUT
IDNUMBER
TESTMARK1
TESTMARK2		 Get ID number, 2 test marks
Calculate the average of the marks
Display the average		 AVERAGE
message

Note on "message": If there is an output message (like "AVERAGE IS 75"), you just write message in the OUTPUT column — you do NOT write the full message text.

Note on PROCESSING: You can say "Get", "Accept", or "Ask user for" — all are acceptable at WSU.

🔗 From IPO Chart → Pseudocode

Each part of the IPO chart maps directly to pseudocode instructions.

BEGIN DECLARE IDNUMBER AS STRING DECLARE TESTMARK1, TESTMARK2 AS REAL DECLARE AVERAGE AS REAL ACCEPT IDNUMBER ACCEPT TESTMARK1 ACCEPT TESTMARK2 AVERAGE = (TESTMARK1 + TESTMARK2) / 2 DISPLAY "AVERAGE IS " AVERAGE END

Mapping: INPUT column → DECLARE + ACCEPT  |  OUTPUT column → DECLARE + DISPLAY  |  PROCESSING column → the body statements

// 02 — design tool

Flowcharts

A flowchart is a graphical representation of program logic using geometric shapes and flowlines. At WSU, we combine pseudocode instructions inside the shapes.

Flowchart Symbols

Each shape has a specific meaning. You must use the correct shape for each instruction.

Oval / Terminal
BEGIN and END only
Rectangle
Processing / calculations / DECLARE / assignments
Parallelogram
ACCEPT (input) and DISPLAY (output)
Diamond
IF condition — two exits: T and F
Small Circle
Connector — continues flowchart on next page
Arrow / Flowline
Connects all symbols — shows direction

📋 Flowchart Rules (WSU)

Every symbol must contain a correct pseudocode instruction

Write real pseudocode (BEGIN, DECLARE, ACCEPT, DISPLAY, IF…THEN, etc.) inside each shape.

Use the correct shape for each instruction

Parallelograms = I/O only. Rectangles = processing only. Diamonds = decisions only.

Declare all variables in the first processing box

Place all DECLARE instructions in the first rectangle after BEGIN.

All symbols must be joined with connecting lines (arrows)

Every shape connects to the next — no floating symbols.

Decision symbol: label both exits T (True) and F (False)

The two lines out of a diamond must always be labelled T and F.

Full Worked Examples

Example 1 — Two prices, display total

"Write a program to ask the user to input 2 prices. Calculate and display the total price."

INPUTPROCESSINGOUTPUT
PRICE1
PRICE2		 Get 2 prices
Calculate and display the total		 TOTAL
BEGIN DECLARE PRICE1, PRICE2 AS REAL DECLARE TOTAL AS REAL DISPLAY "Please input two prices" ACCEPT PRICE1 ACCEPT PRICE2 TOTAL = PRICE1 + PRICE2 DISPLAY "TOTAL IS " TOTAL END

Example 2 — Age check (IF selection)

"Ask the user to input the student's age. If the age is greater than or equal to 18, display 'YOU CAN VOTE'."

INPUTPROCESSINGOUTPUT
AGE Get student's age
If student >= 18 display message		 message
BEGIN DECLARE AGE AS REAL DISPLAY "PLEASE INPUT AGE" ACCEPT AGE IF AGE >= 18 THEN DISPLAY "YOU CAN VOTE" ENDIF END

Example 3 — Discount calculation (IF / ELSE)

"Ask the user to input 2 prices. If the total is greater than R100, subtract 10% discount from the total. Display the final total after the discount."

INPUTPROCESSINGOUTPUT
PRICE1
PRICE2		 Get 2 prices
Calculate the total
If total > R100, subtract 10%
Display total after discount		 TOTAL1
Solution 1 (no ELSE)
BEGIN DECLARE PRICE1,PRICE2,TOTAL1 AS REAL DISPLAY "INPUT TWO PRICES" ACCEPT PRICE1 ACCEPT PRICE2 TOTAL1 = PRICE1 + PRICE2 IF TOTAL1 > 100 THEN TOTAL1 = TOTAL1 - (0.1 * TOTAL1) ENDIF DISPLAY "TOTAL AFTER DISCOUNT" TOTAL1 END
Solution 2 (with ELSE)
BEGIN DECLARE PRICE1,PRICE2,TOTAL1,DISCOUNT AS REAL DISPLAY "INPUT TWO PRICES" ACCEPT PRICE1 ACCEPT PRICE2 TOTAL1 = PRICE1 + PRICE2 IF TOTAL1 > 100 THEN DISCOUNT = 0.1 * TOTAL1 ELSE DISCOUNT = 0 ENDIF TOTAL1 = TOTAL1 - DISCOUNT DISPLAY "TOTAL AFTER DISCOUNT" TOTAL1 END
